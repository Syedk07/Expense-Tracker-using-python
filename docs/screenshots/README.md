# Screenshots

This directory contains screenshots of the SpendWise application.

## How to Add Screenshots

1. Take screenshots of the application in action
2. Save them as PNG files with descriptive names:
   - `dashboard.png` - Main dashboard view
   - `transactions.png` - Transactions management view
   - `reports.png` - Reports and insights view
   - `settings.png` - Settings view
   - `add_expense.png` - Add expense dialog

3. Update the README.md file to reference the actual screenshots

## Recommended Screenshot Dimensions

- Width: 1200-1600px
- Height: 800-1000px
- Format: PNG
- Background: Clean workspace
